---
title: useGSheetWrite
description: Manipulasi data spreadsheet menggunakan fungsi append, update, dan clear.
---

Composable `useGSheetWrite` mengembalikan fungsi-fungsi untuk menambah (`append`), memperbarui (`update`), dan menghapus (`clear`) nilai sel pada Google Sheets.

Operasi penulisan data memerlukan mode autentikasi **`appscript`** atau **`service-account`**.

## Signature

```ts
function useGSheetWrite(globalOptions?: { sheet?: string }): {
  append: (range: string | GSheetWriteOptions, values?: any[][]) => Promise<any>
  update: (range: string | GSheetWriteOptions, values?: any[][]) => Promise<any>
  clear: (range: string | GSheetWriteOptions) => Promise<any>
}
```

## Fungsi Utama

### `append(range, values)`
Menambahkan baris data baru setelah baris terakhir dari range yang ditentukan.

### `update(range, values)`
Menimpa sel yang sudah ada pada range yang ditentukan.

### `clear(range)`
Menghapus konten sel dari range yang ditentukan.

## Contoh Penggunaan

```vue [components/AddForm.vue]
<script setup lang="ts">
const { append, update, clear } = useGSheetWrite({ sheet: 'submissions' })
const isSaving = ref(false)

const handleAppend = async () => {
  isSaving.value = true
  try {
    await append('A1:C1', [
      ['SUB-101', 'Jane Doe', 'jane@example.com']
    ])
    alert('Baris berhasil ditambahkan!')
  }
  finally {
    isSaving.value = false
  }
}

const handleUpdate = async () => {
  await update('B2:C2', [
    ['Jane Smith', 'jane.smith@example.com']
  ])
}

const handleClear = async () => {
  await clear('A5:C5')
}
</script>

<template>
  <div class="actions">
    <button :disabled="isSaving" @click="handleAppend">
      Tambah Baris (Append)
    </button>
    <button @click="handleUpdate">
      Update Baris 2
    </button>
    <button @click="handleClear">
      Hapus Baris 5
    </button>
  </div>
</template>
```

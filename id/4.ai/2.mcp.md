`nuxt-gsheet` menyediakan endpoint server live **Model Context Protocol (MCP)** melalui website Nuxt UI Docs pada [https://nuxtgsheet.permadi.dev/mcp](https://nuxtgsheet.permadi.dev/mcp).

## Setup Client

### Claude Desktop (`claude_desktop_config.json`)

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "nuxt-gsheet": {
      "url": "https://nuxtgsheet.permadi.dev/mcp"
    }
  }
}
```

### Cursor / Antigravity IDE (`.mcp.json`)

```json [.mcp.json]
{
  "servers": {
    "nuxt-gsheet": {
      "url": "https://nuxtgsheet.permadi.dev/mcp",
      "type": "sse"
    }
  }
}
```

Mulai gunakan `nuxt-gsheet` dengan menginstal package, mendaftarkan modul ke konfigurasi Nuxt, dan mengkonfigurasi environment variable.

## Instalasi Package

Tambahkan `nuxt-gsheet` ke proyek kamu menggunakan package manager pilihanmu:

::code-group

```bash [npx]
npx nuxt module add gsheet
```

```bash [bun]
bun add nuxt-gsheet
```

```bash [pnpm]
pnpm add nuxt-gsheet
```

```bash [npm]
npm install nuxt-gsheet
```

```bash [yarn]
yarn add nuxt-gsheet
```

::

## Mendaftarkan Modul

Tambahkan `nuxt-gsheet` ke dalam array `modules` di file `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    'nuxt-gsheet'
  ],

  gsheet: {
    // Opsi default modul (opsional)
    cache: {
      enabled: true,
      maxAge: 300 // TTL cache 5 menit
    }
  }
})
```

## Konfigurasi Environment

Konfigurasikan kredensial Google Sheets atau pengaturan spreadsheet pada file `.env` di root proyek kamu. `nuxt-gsheet` secara otomatis mendeteksi mode autentikasi berdasarkan variabel lingkungan yang kamu definisikan di bawah ini.

### Opsi 1: Mode Google Apps Script (`appscript`)

Gunakan Google Apps Script untuk me-proxy request tanpa perlu membuat kredensial Google Cloud Platform (GCP). Mendukung operasi **Read** dan **Write**.

```env [.env]
GSHEET_APPSCRIPT_URL=https://script.google.com/macros/s/AKfycb.../exec
```

### Opsi 2: Mode Spreadsheet Publik (`gviz` atau `csv`)

Gunakan GViz atau ekspor CSV langsung untuk akses read-only pada spreadsheet publik tanpa konfigurasi rumit. Tidak memerlukan API key maupun kredensial GCP.

```env [.env]
GSHEET_SPREADSHEET_ID=spreadsheet-id-google-kamu
```

### Opsi 3: Mode API Key (`apikey`)

Gunakan Google Sheets API v4 standar untuk spreadsheet publik dengan kontrol kuota kustom.

```env [.env]
GSHEET_SPREADSHEET_ID=spreadsheet-id-google-kamu
GSHEET_API_KEY=AIzaSy...
```

### Opsi 4: Mode Service Account (`service-account`)

Gunakan kredensial GCP Service Account untuk spreadsheet Google privat. Mendukung operasi **Read** dan **Write**.

```env [.env]
GSHEET_SPREADSHEET_ID=spreadsheet-id-google-kamu
GSHEET_CLIENT_EMAIL=service-account-kamu@project-kamu.iam.gserviceaccount.com
GSHEET_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nKUNCI_PRIVATE_KAMU_DI_SINI\n-----END PRIVATE KEY-----\n"
```

::important
Selalu simpan file `.env` kamu di `.gitignore`. Jangan pernah meng-commit private key atau kredensial API ke dalam vcs / repository.
::

## Verifikasi Setup Kamu

Untuk memastikan `nuxt-gsheet` telah terpasang dengan benar:

1. Jalankan development server Nuxt lokal kamu:

```bash
bun run dev
```

2. Buka browser dan jalankan **Nuxt DevTools** (`Shift + Alt + D` atau klik ikon Nuxt di bagian bawah layar).
3. Cari tab **Google Sheets** pada menu DevTools. Jika muncul, modul berhasil dimuat dengan sempurna.

title: Gambaran Umum Mode Autentikasi

---

`nuxt-gsheet` secara otomatis mendeteksi dan mendukung 5 mode autentikasi berbeda tergantung pada tingkat privasi spreadsheet dan kredensial yang kamu gunakan.

## Matriks Perbandingan

| Mode | Kredensial yang Dibutuhkan | Publik / Privat | Read | Write | Batas Kuota |
| :--- | :--- | :---: | :---: | :---: | :--- |
| [**`gviz`**](/id/auth-modes/gviz) | Tidak ada | Publik Saja | Ya | Tidak | Tanpa Kuota (Google Query API) |
| [**`csv`**](/id/auth-modes/csv) | Tidak ada | Publik Saja | Ya | Tidak | Tanpa Kuota (Ekspor CSV Langsung) |
| [**`appscript`**](/id/auth-modes/appscript) | URL Apps Script Web App | Publik & Privat | Ya | Ya | Gratis (Kuota Eksekusi Script) |
| [**`apikey`**](/id/auth-modes/apikey) | GCP API Key | Publik Saja | Ya | Tidak | Batas Standar GCP API |
| [**`service-account`**](/id/auth-modes/service-account) | JSON GCP Service Account | Privat & Publik | Ya | Ya | Batas Standar GCP API |

## Prioritas Deteksi Otomatis

Jika opsi `auth` tidak dideklarasikan secara eksplisit pada `nuxt.config.ts`, `nuxt-gsheet` mendeteksi mode yang aktif berdasarkan environment variable di `.env` dengan urutan prioritas berikut:

1. **`appscript`**: Terdeteksi jika `GSHEET_APPSCRIPT_URL` diisi.
2. **`apikey`**: Terdeteksi jika `GSHEET_API_KEY` diisi.
3. **`service-account`**: Terdeteksi jika `GSHEET_CLIENT_EMAIL` dan `GSHEET_PRIVATE_KEY` diisi.
4. **`gviz` / `csv`**: Mode fallback jika hanya `GSHEET_SPREADSHEET_ID` yang diisi.

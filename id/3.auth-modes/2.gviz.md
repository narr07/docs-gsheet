Mode Google Visualization API (`gviz`) memungkinkan query data berbasis **Read-Only** pada Google Sheets publik tanpa memerlukan Google API Key atau akun GCP.

Mode ini mendukung sintaks Google Query Language (filtering mirip SQL, pemilihan kolom, pengurutan/sorting, dan agregasi).

## Setup

1. Buka Google Sheet kamu -> Klik **Share** (Bagikan) -> Ubah akses menjadi **Anyone with the link can view** (Siapa saja yang memiliki link dapat melihat).
2. Salin Spreadsheet ID dari URL browser:
   `https://docs.google.com/spreadsheets/d/`**`1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms`**`/edit`
3. Tambahkan ke file `.env`:

```env [.env]
GSHEET_SPREADSHEET_ID=1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms
```

## Contoh Query SQL

```vue [pages/products.vue]
<script setup lang="ts">
// Pilih kolom A, B, C dengan kondisi harga (Kolom C) > 50 diurutkan dari yang tertinggi
const { data: topProducts } = await useGSheetAsObject('A1:C100', {
  sheet: 'products',
  query: 'SELECT A, B, C WHERE C > 50 ORDER BY C DESC'
})
</script>
```

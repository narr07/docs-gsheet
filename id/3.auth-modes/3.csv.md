Mode CSV me-stream ekspor data CSV mentah langsung dari endpoint Google Sheets untuk spreadsheet publik.

Mode ini sangat ringan dan cepat untuk dumping tabel utuh ke dalam bentuk array.

## Setup

1. Bagikan Google Sheet kamu sebagai **Anyone with the link can view**.
2. Tambahkan ke file `.env`:

```env [.env]
GSHEET_SPREADSHEET_ID=spreadsheet-id-google-kamu
```

## Contoh Penggunaan

```vue [pages/catalog.vue]
<script setup lang="ts">
const { data: rows } = await useGSheet('A1:Z100', {
  sheet: 'Catalog'
})
</script>
```

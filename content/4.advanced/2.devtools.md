`nuxt-gsheet` integrates directly into **Nuxt DevTools** by registering a custom iframe tab.

## Accessing DevTools

1. Launch your dev server (`bun dev`).
2. Press `Shift + Alt + D` in your browser.
3. Click the **Google Sheets** tab.

## Dashboard Capabilities

- **Interception Log**: View all server-proxied API requests in real time.
- **Cache Hit / Miss Ratio**: Monitor caching performance.
- **Active Auth Mode**: Verify whether `gviz`, `appscript`, `apikey`, or `service-account` is active.
- **Quota Estimates**: Track estimated API usage.

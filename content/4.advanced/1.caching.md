`nuxt-gsheet` includes a server-side caching engine equipped with **Stampede Lock Protection**.

## How Stampede Lock Works

When cache expires on a high-traffic site, traditional fetching causes hundreds of concurrent client requests to hit Google API endpoints at once, causing HTTP 429 quota exhaustion.

`nuxt-gsheet` collapses concurrent identical requests into a single upstream fetch:

```
Request 1 (Client A) ──┐
Request 2 (Client B) ──┼──> [Stampede Lock] ──> Single Fetch to Google Sheets
Request 3 (Client C) ──┘
```

## Bypassing Cache

To bypass cache for a specific request:

```ts
const { data, refresh } = await useGSheet('A1:B10', {
  cache: false // Bypasses server cache for this request
})

// Or call refresh()
await refresh()
```

`nuxt-gsheet` runs seamlessly across all Nitro deployment presets (Vercel, Netlify, Cloudflare Pages, AWS Lambda, Node server, Bun server).

## Environment Variables Checklist

Ensure environment variables are configured in your hosting dashboard:

- `GSHEET_SPREADSHEET_ID`
- `GSHEET_APPSCRIPT_URL` (if using Apps Script)
- `GSHEET_CLIENT_EMAIL` & `GSHEET_PRIVATE_KEY` (if using Service Account)

::warning
When setting `GSHEET_PRIVATE_KEY` on Vercel or Netlify, escape newline characters properly or paste the multiline string according to the hosting platform's env guidelines.
::

title: Model Context Protocol (MCP)
description: Connect AI assistants to the live nuxt-gsheet MCP documentation server.
---

`nuxt-gsheet` provides a live **Model Context Protocol (MCP)** server endpoint via its Nuxt UI Docs website at [https://nuxtgsheet.permadi.dev/mcp](https://nuxtgsheet.permadi.dev/mcp).

## Client Setup

### Claude Desktop (`claude_desktop_config.json`)

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "nuxt-gsheet": {
      "url": "https://nuxtgsheet.permadi.dev/mcp"
    }
  }
}
```

### Cursor / Antigravity IDE (`.mcp.json`)

```json [.mcp.json]
{
  "servers": {
    "nuxt-gsheet": {
      "url": "https://nuxtgsheet.permadi.dev/mcp",
      "type": "sse"
    }
  }
}
```

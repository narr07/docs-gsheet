---
title: useGSheetAsObject
description: Map first-row header labels to JavaScript objects automatically.
---

The `useGSheetAsObject` composable maps spreadsheet rows into an array of typed key-value objects using the column headers in the first row.

## Signature

```ts
function useGSheetAsObject<T = any[]>(
  range: string,
  options?: ComposablesOptions
): {
  data: Ref<T | null>
  pending: Ref<boolean>
  error: Ref<FetchError | null>
  refresh: () => Promise<void>
  execute: () => Promise<void>
  status: Ref<'idle' | 'pending' | 'success' | 'error'>
}
```

## How It Works

If your spreadsheet range `A1:C3` contains:

| A | B | C |
| :--- | :--- | :--- |
| **id** | **name** | **price** |
| 101 | Wireless Mouse | 29.99 |
| 102 | Mechanical Keyboard | 89.99 |

`useGSheetAsObject('A1:C3')` outputs:

```json
[
  { "id": 101, "name": "Wireless Mouse", "price": 29.99 },
  { "id": 102, "name": "Mechanical Keyboard", "price": 89.99 }
]
```

## Basic Example

```vue [pages/products.vue]
<script setup lang="ts">
interface Product {
  id: string
  name: string
  price: string
}

const { data: products, pending } = await useGSheetAsObject<Product[]>('A1:C50', {
  sheet: 'products'
})
</script>

<template>
  <div v-if="pending">Loading products...</div>
  <ul v-else>
    <li v-for="product in products" :key="product.id">
      {{ product.name }} - ${{ product.price }}
    </li>
  </ul>
</template>
```

Each row of Google's public sample spreadsheet becomes an object keyed by the header labels. This example shows two of those keys:

::code-preview
:::gsheet-table{range="A1:F6" sheet="Class Data" columns="Student Name,Major"}

#code
```vue [pages/students.vue]
<script setup lang="ts">
const { data: students } = await useGSheetAsObject('A1:F6', { sheet: 'Class Data' })
</script>

<template>
  <table>
    <thead>
      <tr>
        <th>Student Name</th>
        <th>Major</th>
      </tr>
    </thead>
    <tbody>
      <tr v-for="student in students" :key="student['Student Name']">
        <td>{{ student['Student Name'] }}</td>
        <td>{{ student.Major }}</td>
      </tr>
    </tbody>
  </table>
</template>
```

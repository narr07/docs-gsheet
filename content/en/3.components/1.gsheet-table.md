---
title: GsheetTable
description: Render a sheet range as a table, straight from a Markdown file.
---

`<GsheetTable>` turns a sheet range into an HTML table. The module registers it globally, so you can call it from a Markdown file with one line and from any `.vue` file.

The first row of the range becomes the table header. Data goes through the same server proxy and cache as the composables, and the table is rendered on the server.

## Live Example

This table reads Google's public [sample spreadsheet](https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit):

::code-preview
:::gsheet-table{range="A1:F31" sheet="Class Data" columns="Student Name,Class Level,Major" limit="8"}
:::

#code
```md [content/index.md]
::gsheet-table{range="A1:F31" sheet="Class Data" columns="Student Name,Class Level,Major" limit="8"}
::
```
::

## Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| `range` | `string` | Cell range to read. The first row is used as headers. Required. |
| `sheet` | `string` | Sheet name, or a key from the `sheets` map in `nuxt.config`. |
| `columns` | `string \| string[]` | Header names to show, in that order. Matching ignores case, and unknown names are skipped. |
| `limit` | `number \| string` | Maximum number of body rows. |
| `offset` | `number \| string` | Number of body rows to skip before the first one shown. |
| `query` | `string` | GViz query, for `gviz` mode only. |

Without `columns`, every column in the range is shown.

## In Markdown

With Nuxt Content, use the MDC block syntax. No import is needed:

```md
::gsheet-table{range="A1:C50" sheet="products"}
::
```

Pass an array with a bound prop when a header name contains a comma:

```md
::gsheet-table{range="A1:C50" :columns='["Name", "Price, USD"]'}
::
```

## With Comark

[Comark](https://comark.dev) uses the same block syntax. Its Vue renderer picks up globally registered components, so `::gsheet-table` works as is. You can also pass the component explicitly:

```vue [pages/index.vue]
<script setup lang="ts">
import { Markdown } from '@comark/vue'
import { GsheetTable } from '#components'

const content = `
::gsheet-table{range="A1:C50" sheet="products"}
::
`
</script>

<template>
  <Markdown :components="{ GsheetTable }">{{ content }}</Markdown>
</template>
```

## In a Vue File

```vue [pages/products.vue]
<template>
  <GsheetTable
    range="A1:C50"
    sheet="products"
    :columns="['name', 'price']"
    :limit="10"
  />
</template>
```

## Styling

The component ships a few low-specificity defaults: a bottom border per row, cell padding, and horizontal scrolling on narrow screens. Any stylesheet overrides them through these classes:

| Class | Element |
| :--- | :--- |
| `.gsheet-table-wrapper` | Scroll container around the table. |
| `.gsheet-table` | The `<table>` element. |
| `.gsheet-table-status` | Loading, empty, and error messages. |
| `.gsheet-table-error` | Added to the message when the request fails. |

## Limits

A plain Markdown viewer such as GitHub or npm does not run components, so `::gsheet-table` shows up there as text. The table needs a renderer that resolves Vue components.

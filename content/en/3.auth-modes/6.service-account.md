---
title: Service Account Mode
description: Enterprise-grade Read & Write access for private, unshared Google Sheets.
---

Service Account mode uses GCP Service Account credentials (client email & private key JSON) to access private Google Sheets.

## Setup

1. Create a Service Account in GCP Console.
2. Download JSON key file.
3. Share your private Google Sheet with the Service Account email as **Editor**.
4. Configure `.env`:

```env [.env]
GSHEET_SPREADSHEET_ID=your-private-spreadsheet-id
GSHEET_CLIENT_EMAIL=your-service-account@project.iam.gserviceaccount.com
GSHEET_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nYOUR_KEY\n-----END PRIVATE KEY-----\n"
```

## Example

```vue [pages/orders.vue]
<script setup lang="ts">
const { data: orders, refresh } = await useGSheetAsObject('A1:D50', { sheet: 'Orders' })
const { append } = useGSheetWrite({ sheet: 'Orders' })

const saveOrder = async () => {
  await append('A1:D1', [['ORD-101', 'Acme', '99.00', 'Paid']])
  await refresh()
}
</script>
```

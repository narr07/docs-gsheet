`nuxt-gsheet` automatically detects and supports 5 distinct authentication modes depending on your spreadsheet privacy and credential setup.

## Comparison Matrix

| Mode | Credentials Needed | Public / Private | Read | Write | Quota Limit |
| :--- | :--- | :---: | :---: | :---: | :--- |
| [**`gviz`**](/auth-modes/gviz) | None | Public Only | Yes | No | Uncapped (Google Query API) |
| [**`csv`**](/auth-modes/csv) | None | Public Only | Yes | No | Uncapped (Direct CSV export) |
| [**`appscript`**](/auth-modes/appscript) | Apps Script Web App URL | Public & Private | Yes | Yes | Free (Script Execution Quotas) |
| [**`apikey`**](/auth-modes/apikey) | GCP API Key | Public Only | Yes | No | Standard GCP API Limits |
| [**`service-account`**](/auth-modes/service-account) | GCP Service Account JSON | Private & Public | Yes | Yes | Standard GCP API Limits |

## Automatic Detection Priority

If `auth` is not explicitly declared in `nuxt.config.ts`, `nuxt-gsheet` detects the active mode based on defined environment variables in this order:

1. **`appscript`**: Detected if `GSHEET_APPSCRIPT_URL` is present.
2. **`service-account`**: Detected if `GSHEET_CLIENT_EMAIL` and `GSHEET_PRIVATE_KEY` are present.
3. **`apikey`**: Detected if `GSHEET_API_KEY` is present.
4. **`gviz` / `csv`**: Fallback mode if only `GSHEET_SPREADSHEET_ID` is present.

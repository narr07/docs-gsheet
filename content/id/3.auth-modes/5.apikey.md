---

Mode API Key menggunakan endpoint resmi Google Sheets API v4 untuk spreadsheet publik dengan pemantauan kuota GCP API secara presisi.

## Setup

1. Buat API Key pada [Google Cloud Console](https://console.cloud.google.com).
2. Tambahkan kredensial ke file `.env`:

```env [.env]
GSHEET_SPREADSHEET_ID=spreadsheet-id-kamu
GSHEET_API_KEY=AIzaSy...
```

## Contoh Penggunaan

```vue [pages/inventory.vue]
<script setup lang="ts">
const { data: stock } = await useGSheetAsObject('A1:C20', {
  sheet: 'Inventory'
})
</script>
```

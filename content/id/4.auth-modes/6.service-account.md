---
title: Mode Service Account
description: Akses Read & Write tingkat enterprise untuk Google Sheets privat yang tidak dibagikan publik.
---

Mode Service Account menggunakan kredensial GCP Service Account (client email & private key JSON) untuk mengakses Google Sheets privat secara aman.

## Setup

1. Buat Service Account pada GCP Console.
2. Unduh file kunci JSON.
3. Bagikan Google Sheet privat kamu ke alamat email Service Account sebagai **Editor**.
4. Konfigurasikan file `.env`:

```env [.env]
GSHEET_SPREADSHEET_ID=spreadsheet-id-privat-kamu
GSHEET_CLIENT_EMAIL=service-account-kamu@project.iam.gserviceaccount.com
GSHEET_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nKUNCI_KAMU\n-----END PRIVATE KEY-----\n"
```

## Contoh Penggunaan

```vue [pages/orders.vue]
<script setup lang="ts">
const { data: orders, refresh } = await useGSheetAsObject('A1:D50', { sheet: 'Orders' })
const { append } = useGSheetWrite({ sheet: 'Orders' })

const saveOrder = async () => {
  await append('A1:D1', [['ORD-101', 'Acme', '99.00', 'Paid']])
  await refresh()
}
</script>
```

title: Mode Google Apps Script
description: Operasi Read dan Write gratis menggunakan proxy Google Apps Script Web App.
---

Mode Google Apps Script memungkinkan operasi **Read** dan **Write** (append, update, clear) tanpa perlu membuat kredensial Google Cloud Platform (GCP) atau membayar biaya penggunaan API.

## Setup & Deployment

1. Buka Google Sheet -> **Extensions** -> **Apps Script**.
2. Tempelkan skrip handler `Code.gs` berikut:

```javascript [Code.gs]
function doGet(e) {
  const sheetName = e.parameter.sheet || 'Sheet1';
  const range = e.parameter.range || 'A1:Z100';
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(sheetName);
  const values = sheet.getRange(range).getValues();
  return ContentService.createTextOutput(JSON.stringify(values)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(data.sheet || 'Sheet1');
  if (data.values) {
    data.values.forEach(r => sheet.appendRow(r));
  }
  return ContentService.createTextOutput(JSON.stringify({ success: true })).setMimeType(ContentService.MimeType.JSON);
}
```

3. Klik **Deploy** -> **New Deployment** -> Pilih tipe **Web App**.
4. Atur **Execute as**: *Me*, **Who has access**: *Anyone*.
5. Salin URL Web App ke file `.env`:

```env [.env]
GSHEET_APPSCRIPT_URL=https://script.google.com/macros/s/.../exec
```

## Contoh (Read & Write)

```vue [pages/feedback.vue]
<script setup lang="ts">
const { data: items } = await useGSheetAsObject('A1:C50', { sheet: 'Feedback' })
const { append } = useGSheetWrite({ sheet: 'Feedback' })

const addFeedback = async () => {
  await append('A1:C1', [['101', 'Alex', 'Modul yang luar biasa!']])
}
</script>
```

Composable `useGSheetAsObject` memetakan baris-baris spreadsheet menjadi array objek key-value menggunakan label header kolom pada baris pertama.

## Signature

```ts
function useGSheetAsObject<T = any[]>(
  range: string,
  options?: ComposablesOptions
): {
  data: Ref<T | null>
  pending: Ref<boolean>
  error: Ref<FetchError | null>
  refresh: () => Promise<void>
  execute: () => Promise<void>
  status: Ref<'idle' | 'pending' | 'success' | 'error'>
}
```

## Cara Kerja

Jika range spreadsheet kamu `A1:C3` berisi:

| A | B | C |
| :--- | :--- | :--- |
| **id** | **name** | **price** |
| 101 | Wireless Mouse | 29.99 |
| 102 | Mechanical Keyboard | 89.99 |

Maka `useGSheetAsObject('A1:C3')` menghasilkan output:

```json
[
  { "id": 101, "name": "Wireless Mouse", "price": 29.99 },
  { "id": 102, "name": "Mechanical Keyboard", "price": 89.99 }
]
```

## Contoh Penggunaan

```vue [pages/products.vue]
<script setup lang="ts">
interface Product {
  id: string
  name: string
  price: string
}

const { data: products, pending } = await useGSheetAsObject<Product[]>('A1:C50', {
  sheet: 'products'
})
</script>

<template>
  <div v-if="pending">Memuat produk...</div>
  <ul v-else>
    <li v-for="product in products" :key="product.id">
      {{ product.name }} - ${{ product.price }}
    </li>
  </ul>
</template>
```

## Contoh Langsung

Setiap baris spreadsheet contoh publik milik Google menjadi objek dengan key dari label header, jadi kolom tabel bisa langsung menunjuk ke key tersebut:

#code

```vue [pages/students.vue]
<script setup lang="ts">
const { data: students } = await useGSheetAsObject('A1:F6', { sheet: 'Class Data' })

const columns = [
  { accessorKey: 'Student Name', header: 'Student Name' },
  { accessorKey: 'Class Level', header: 'Class Level' },
  { accessorKey: 'Major', header: 'Major' }
]
</script>

<template>
  <UTable
    :data="students ?? []"
    :columns="columns"
    class="w-full"
  />
</template>
```
:::
::

Tabel di atas memakai [`UTable`](https://ui.nuxt.com/docs/components/table) dari Nuxt UI. Untuk mendapat tabel tanpa menulis komponen, pakai [`GsheetTable`](/id/components/gsheet-table) di Markdown.

Composable `useGSheetRow` mengambil satu baris tunggal dari range berdasarkan indeks berbasis nol (zero-based index).

## Signature

```ts
function useGSheetRow<T = any>(
  range: string,
  rowIndex: number,
  options?: ComposablesOptions
): {
  data: Ref<T | null>
  pending: Ref<boolean>
  error: Ref<FetchError | null>
  refresh: () => Promise<void>
  execute: () => Promise<void>
  status: Ref<'idle' | 'pending' | 'success' | 'error'>
}
```

## Parameter

| Parameter | Tipe | Wajib | Deskripsi |
| :--- | :--- | :---: | :--- |
| `range` | `string` | **Ya** | Range sel dalam notasi A1. |
| `rowIndex` | `number` | **Ya** | Indeks berbasis nol untuk baris target di dalam range. |
| `options` | `ComposablesOptions` | Tidak | Opsi composable tambahan. |

## Contoh Penggunaan

```vue [pages/profile.vue]
<script setup lang="ts">
// Mengambil indeks 1 (baris kedua pada range A1:C10)
const { data: userRow, pending } = await useGSheetRow('A1:C10', 1, {
  sheet: 'users'
})
</script>

<template>
  <div v-if="pending">Memuat pengguna...</div>
  <div v-else-if="userRow">
    <p>ID Pengguna: {{ userRow[0] }}</p>
    <p>Nama: {{ userRow[1] }}</p>
    <p>Peran: {{ userRow[2] }}</p>
  </div>
</template>
```

## Contoh Langsung

Satu siswa dari spreadsheet contoh publik milik Google, dibaca lewat index baris dan ditampilkan bersama baris header:

::code-preview
:::gsheet-table{range="A1:F31" sheet="Class Data" offset="2" limit="1"}
:::

#code
```vue [pages/student.vue]
<script setup lang="ts">
const options = { sheet: 'Class Data' }

// Index 0 adalah baris header, index 3 adalah siswa ketiga
const { data: headers } = await useGSheetRow('A1:F31', 0, options)
const { data: student } = await useGSheetRow('A1:F31', 3, options)
</script>

<template>
  <table v-if="headers && student">
    <thead>
      <tr>
        <th v-for="header in headers" :key="header">{{ header }}</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td v-for="(cell, index) in student" :key="index">{{ cell }}</td>
      </tr>
    </tbody>
  </table>
</template>
```
::

Pratinjau di atas dirender oleh [`GsheetTable`](/id/components/gsheet-table), yang menghasilkan tabel yang sama dari satu baris Markdown.

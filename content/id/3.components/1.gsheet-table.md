---
title: GsheetTable
description: Tampilkan range sheet sebagai tabel, langsung dari file Markdown.
---

`<GsheetTable>` mengubah range sheet menjadi tabel HTML. Modul mendaftarkannya secara global, jadi kamu bisa memanggilnya dari file Markdown dengan satu baris, juga dari file `.vue` mana pun.

Baris pertama range menjadi header tabel. Datanya melewati server proxy dan cache yang sama dengan composable, dan tabelnya dirender di server.

## Contoh Langsung

Tabel ini membaca [spreadsheet contoh](https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit) publik milik Google:

::gsheet-table{range="A1:F31" sheet="Class Data" columns="Student Name,Class Level,Major" limit="8"}
::

```md [content/index.md]
::gsheet-table{range="A1:F31" sheet="Class Data" columns="Student Name,Class Level,Major" limit="8"}
::
```

## Props

| Prop | Tipe | Keterangan |
| :--- | :--- | :--- |
| `range` | `string` | Range sel yang dibaca. Baris pertama dipakai sebagai header. Wajib diisi. |
| `sheet` | `string` | Nama sheet, atau key dari map `sheets` di `nuxt.config`. |
| `columns` | `string \| string[]` | Nama header yang ditampilkan, sesuai urutan penulisan. Huruf besar-kecil diabaikan, dan nama yang tidak ditemukan dilewati. |
| `limit` | `number \| string` | Jumlah maksimum baris isi. |
| `offset` | `number \| string` | Jumlah baris isi yang dilewati sebelum baris pertama yang ditampilkan. |
| `query` | `string` | Query GViz, khusus mode `gviz`. |

Tanpa `columns`, semua kolom dalam range ditampilkan.

## Di Markdown

Dengan Nuxt Content, pakai sintaks blok MDC. Tidak perlu import:

```md
::gsheet-table{range="A1:C50" sheet="products"}
::
```

Kalau nama header mengandung koma, kirim array lewat prop yang di-bind:

```md
::gsheet-table{range="A1:C50" :columns='["Name", "Price, USD"]'}
::
```

## Dengan Comark

[Comark](https://comark.dev) memakai sintaks blok yang sama. Renderer Vue-nya mengenali komponen yang terdaftar global, jadi `::gsheet-table` langsung berfungsi. Kamu juga bisa mengoper komponennya secara eksplisit:

```vue [pages/index.vue]
<script setup lang="ts">
import { Markdown } from '@comark/vue'
import { GsheetTable } from '#components'

const content = `
::gsheet-table{range="A1:C50" sheet="products"}
::
`
</script>

<template>
  <Markdown :components="{ GsheetTable }">{{ content }}</Markdown>
</template>
```

## Di File Vue

```vue [pages/products.vue]
<template>
  <GsheetTable
    range="A1:C50"
    sheet="products"
    :columns="['name', 'price']"
    :limit="10"
  />
</template>
```

## Styling

Komponen ini membawa beberapa gaya bawaan dengan spesifisitas rendah: garis bawah di tiap baris, padding sel, dan scroll horizontal di layar sempit. Stylesheet apa pun bisa menimpanya lewat class berikut:

| Class | Elemen |
| :--- | :--- |
| `.gsheet-table-wrapper` | Kontainer scroll di sekeliling tabel. |
| `.gsheet-table` | Elemen `<table>`. |
| `.gsheet-table-status` | Pesan loading, kosong, dan error. |
| `.gsheet-table-error` | Ditambahkan ke pesan saat request gagal. |

## Batasan

Penampil Markdown polos seperti GitHub atau npm tidak menjalankan komponen, jadi di sana `::gsheet-table` hanya tampil sebagai teks. Tabel ini butuh renderer yang bisa memuat komponen Vue.
